### ¿Qué es esto?

GasDrive Click no es un test de preguntas. Es un **simulador de cabina S-03** donde cada imagen es una situación real de examen DGT.

Cada escena tiene **3 capas** que ninguna autoescuela tiene juntas:

1. **Capa SIM:** Cabina real con volante, 50 km/h, modo simulador. Inmersión total.
2. **Capa DGT:** Señal oficial con código exacto (R-02, M-7.10, P-24) + norma (Art 151 RGC).
3. **Capa TRAMPA:** El error que hace suspender al 90% (STOP oculto, glorieta turbo, cuadrícula amarilla).

### 🚀 Tandas 1-10 Completadas - 100 Escenas S-03

Base oficial validada - 10% del objetivo 1.000:

- **T1 (1-10):** Ciudad básica, glorieta, STOP, MEC, AUX, moto
- **T2 (11-20):** Carretera, autovía A-3, pesado, V-20, tacógrafo
- **T3 (21-30):** S-28 radar, VAO, distancia seguridad, RCP
- **T4 (31-40):** Urbano: semáforo, bus, tranvía, VMP, zona azul
- **T5 (41-50):** Adversas: noche, lluvia, niebla, túnel, nieve, viento
- **T6 (51-60):** A-3 Valencia, adelantamientos, prioritarios, peaje, alcoholemia
- **T7 (61-70):** Cruces sin señalizar, rasante, curva, paso a nivel
- **T8 (71-80):** Glorieta partida/turbo, carril bici, animales P-23/P-24, ADR, ITV, carga V-20
- **T9 (81-90):** Frenada ABS/ESP, reventón, retenciones, reversibles, aquaplaning
- **T10 (91-100):** Drogas, fármacos, sueño, móvil 6 puntos, GPS, cinturón, SRI, marcas viales M

> Con 100 imágenes = 300 preguntas automáticas (EDU + TRAMPA + EXAMEN).
